# 30 Days of AI Engineering 🚀

A hands-on journey to becoming an AI Engineer through daily coding, practical projects, and real-world AI applications.

## 🛠️ Tech Stack

- Python
- OpenAI LLMs
- LangChain & LangGraph
- RAG & ChromaDB
- MCP (Model Context Protocol)
- FastAPI & Pydantic

## 📚 Progress

- **Days 1–4:** LLMs, embeddings, and RAG
- **Days 5–10:** AI agents and LangChain
- **Days 11–13:** LangGraph workflows and human-in-the-loop
- **Days 14–16:** Hybrid search and MCP
- **Day 17:** Multi-agent travel planner
- **Day 18:** Prompt injection and tool permissions
- **Day 19:** FastAPI integration, validation, and error handling

## 🎯 Goal

Build, test, and deploy practical AI projects while developing skills in RAG, agentic AI, and production-ready AI engineering.

*Learning by building, one day at a time.*
